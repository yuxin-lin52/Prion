# 11 并发

## 概述

并发用任务 token 表达。`spawn` 启动任务体并产出 `token(T)`；`join` 等待任务并返回其值。token 必须在其所在块结束前被 join，不存在隐式游离的任务。

## 派生与汇合

```anle
add val "t" token(int) = spawn:
    give 42
;
add val "r" int = join(call val "t")
```

`spawn:` 打开任务体，`give` 提供结果。会逃出块的 token 是编译错误。

不需要结果的任务以单独的 `join` 结尾，表示自结束：

```anle
add val "t" token(void) = spawn:
    add val "x" int = 1 + 1
    join
;
```

自结束任务不能捕获外层值，因为父块可能先退出。

## 共享与移交

默认情况下任务不能触碰外层值，因为编译器无法判断是否线程安全。这一点通过标记显式放行：

- `add share val "n" int = 21`——任务间只读共享。
- `add val(send) "x" int = 7`——把所有权移交给单个任务。

`share` 与 `(send)` 互斥。`share` 值不能写。`(send)` 值一经移交，原处即失效；一个值最多移交一次。

## 示例

```anle
#: main b
    add val "t" token(int) = spawn:
        give 42
    ;
    add val "r" int = join(call val "t")
    print("result", call val "r")

    add share val "base" int = 21
    add val "u" token(int) = spawn:
        give call val "base" * 2
    ;
    print("shared", join(call val "u"))
#: main d
```

输出：

```
result 42
shared 42
```

## 规则

- 每次 `spawn` 产出一个 token；每个 token 或被 join，或任务体以 `join` 自结束。
- 装 token 的容器在块内整体 join 一次。
- 失败随 `join` 传播。
- 一个值最多移交一次；只读共享使用 `add share val`。
