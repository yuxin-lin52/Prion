# 11 并发

Prion 用**任务 token** 表达并发。你 `spawn` 一个任务体，它产出一个 `token(T)`，且必须在块结束前 `join`。没有任何东西是隐式游离的。

## 派生与汇合

```anle
add val "t" token(int) = spawn:
    give 42
;
add val "r" int = join(call val "t")
```

`spawn:` 打开任务体，`give` 提供结果。`join(call val "t")` 等待任务并返回它的值。每个派生的 token 都必须被 join——逃出块的 token 是编译错误。

## 共享与移交

默认情况下任务不能碰外层值，因为编译器无法判断这是否线程安全。你用标记显式放行：

- `add share val "n" int = 21`——任务间只读共享。
- `add val(send) "x" int = 7`——把所有权移交给单个任务。

`share` 与 `(send)` 互斥，且 `share` 值不能写。`(send)` 值一旦移交，原处就失效。

## 动手试试

```anle
#: main b
    add val "t" token(int) = spawn:
        give 42
    ;
    add val "r" int = join(call val "t")
    print("result", call val "r")

    add share val "base" int = 21
    add val "u" token(int) = spawn:
        give call val "base" * 2
    ;
    print("shared", join(call val "u"))
#: main d
```

预期输出：

```
result 42
shared 42
```

## 自结束任务

当任务不需要结果时，在任务体末尾写一个单独的 `join` 表示自结束：

```anle
add val "t" token(void) = spawn:
    add val "x" int = 1 + 1
    join
;
```

自结束任务不能捕获外层值，因为父块可能先退出。

## 规则一览

- 每次 spawn 产出一个 token；每个 token 要么被 join，要么任务体用 `join` 自结束。
- 装 token 的容器必须在块内整体 join 一次。
- 一个值最多移交一次；只读共享请用 `add share val`。
