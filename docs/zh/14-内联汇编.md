# 14 内联汇编

内联汇编让你在 `unsafe` 块里直接落到机器指令。它是三类「仅限 unsafe」的能力之一（与裸地址读写、C 互操作并列）。

## 形式

```anle
asm("模板" : 输出 : 输入 : 破坏)
```

- **模板**是指令字符串（只准 ASCII）。
- **输出**段把寄存器绑定到 Prion 名：`寄存器 -> 名`（只写）或 `寄存器 <-> 名`（读写）。
- **输入**段把寄存器绑定到表达式：`寄存器 <- 表达式`。
- **破坏**段列出被破坏的寄存器，或 `memory` / `cc`。

四段用 `:` 分隔。寄存器名映射到 Prion 寄存器，例如 `al/ax/eax/rax -> a`、`r8..r15 -> r8..r15`。

## 动手试试

```anle
#: raw b unsafe
    add val "reg" uint_8 = 0
    asm("movb $9, %[reg]" : al -> reg : : memory)
    print("asm out", call val "reg")
#: raw d
```

预期输出：

```
asm out 9
```

## 规则

- `asm` 只能出现在 `#: 名 b unsafe` 的块里。
- `asm` 是**动作语句**——它没有输出值，不能像表达式那样赋值。输出要绑定到已有的 val。
- 输出绑定的每个名字都必须已在同块用 `add val` 建过。
- 隔离区（引号内）必须 ASCII；任何非 ASCII 字符都报错。

## 为什么要围起来

汇编绕开了 Prion 的全部类型与内存规则。把它限制在 `unsafe` 块内，意味着读一个普通块就能确切知道里面会不会跑危险代码。
