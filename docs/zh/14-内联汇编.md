# 14 内联汇编

## 概述

内联汇编允许在 `unsafe` 块内嵌入机器指令。它与裸地址访问、C 互操作并列为三类「仅限 unsafe」的能力。

## 形式

```prion
asm("模板" : 输出 : 输入 : 破坏)
```

- **模板**——指令字符串，只准 ASCII。
- **输出**——把寄存器绑定到 Prion 名：`寄存器 -> 名`（只写）或 `寄存器 <-> 名`（读写）。
- **输入**——把寄存器绑定到表达式：`寄存器 <- 表达式`。
- **破坏**——寄存器名，或 `memory` / `cc`。

四段以 `:` 分隔。寄存器名映射到 Prion 寄存器，例如 `al/ax/eax/rax -> a`、`r8..r15 -> r8..r15`。

## 示例

```prion
#: raw b unsafe
    add val "reg" uint_8 = 0
    asm("movb $9, %[reg]" : al -> reg : : memory)
    print("asm out", call val "reg")
#: raw d
```

输出：

```
asm out 9
```

## 规则

- `asm` 只能出现在声明为 `#: 名 b unsafe` 的块内。
- `asm` 是动作语句：没有输出值，不能像表达式那样赋值。输出绑定到已有的 val。
- 输出绑定的每个名字都必须已在同块用 `add val` 定义。
- 隔离区（引号内）必须是 ASCII；非 ASCII 字符会报错。

## 理由

汇编绕开了 Prion 的全部类型与内存规则。把它限制在 `unsafe` 块内，意味着阅读一个普通块即可知道其中不运行汇编。
