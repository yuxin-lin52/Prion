# 02 基本概念

## 概述

四条规则贯穿所有 Prion 程序：代码位于扁平的块内；名字用 `add` 只创建一次；读取与调用显式写出类别；值在所属块结束时释放。本章定义这些规则并演示标量类型。

## 块

块以 `#: 名 b` 打开、以 `#: 名 d` 关闭。块是扁平的，不嵌套。

运行时块形成链。不被任何块引用的块是链根，链根按源码顺序自上而下执行；被引用的块在调用处执行。两个仅互相引用、且没有链根的块会在编译期被拒绝，因为它们永远无法执行。

## 创建与重绑定

名字用 `add` 创建，且只创建一次：

```prion
add val "x" int = 1
add fn "f" (n int) int = n
add type "point" = (x int, y int)
```

重绑定不使用 `add`：

```prion
val "x" = 2
val "x" = val "x" (+1)
```

对从未创建的名字赋值是编译错误。不存在「首次赋值即创建变量」的规则，因此拼错的名字会被报告，而不会悄悄变成新变量。

## 显式读取与调用

读取写作 `call val "x"`；调用写作 `call fn "f"(1)`。裸标识符会被拒绝，因为函数与值可以重名，裸名无法说明指向哪一个。

两个动词构成读取面：

- `call` 引用最新的值。
- `take` 按此刻的值做深拷贝。

内存在所属块结束时释放；没有提前释放内存的语句。

## 标量类型

```prion
int  float  bool  str
int_8 int_16 int_32 int_64  uint_8 uint_16 uint_32 uint_64
```

## 示例

```prion
#: main b
    add val "i" int = 42
    add val "r" float = 1.5
    add val "b" bool = re
    add val "s" str = "abc"
    add val "u8" uint_8 = 200
    add val "nil" str = null
    print("int", call val "i")
    print("float", call val "r")
    print("bool", call val "b")
    print("str", call val "s")
    print("uint8", call val "u8")
    if call val "nil" == null:
        print("null check", "ok")
    ;
#: main d
```

输出：

```
int 42
float 1.5
bool re
str abc
uint8 200
null check ok
```

## 规则

- 块既是执行单位也是内存单位，因此不允许嵌套。
- 每个名字只 `add` 一次；重复创建是编译错误。
- 读取与调用都写出动词；不存在裸标识符。
- 值在块结束时释放，寿命不超过所属块。
