# 02 基本概念

本章讲写任何真实 Prion 代码之前必须掌握的四个概念：块、一次性创建、全面显式、动词槽。学完你会运行一个用上全部标量类型的小程序。

## 块

所有代码都在块里。块用 `#: 名 b` 打开，用 `#: 名 d` 关闭。块是**平的**——永不嵌套。

运行时块会成链：不被任何块引用的块是**链根**，链根按源码顺序从上到下依次执行；被引用的块在调用处执行。两个互相调用且没有链根的块在编译期被拒绝（它们永远跑不到）。

## 只创建一次，之后是重新绑定

名字用 `add` 创建，且只创建一次：

```anle
add val "x" int = 1                 // 创建一个值
add fn "f" (n int) int = n          // 创建一个函数
add type "point" = (x int, y int)   // 创建一个类型
```

重新绑定永不使用 `add`，而是普通赋值：

```anle
val "x" = 2
val "x" = val "x" (+1)
```

给一个从未创建过的名字赋值是编译错误。不存在「第一次赋值顺便创建变量」的说法：拼错的名字会当场报错，而不会悄悄变成一个新变量。

## 全面显式

读取要写出动词：`call val "x"`。调用要写出动词：`call fn "f"(1)`。裸标识符 `x` 会被拒绝——函数和值可以重名，裸名无法说明你要的是哪一个。

## 动词槽

- `call`——引用最新的值。
- `take`——按「此刻的样子」深拷贝。
- `kill`——显式提前回收（只在 `unsafe` 块里用；见 [08](08-内存模型.md)）。

## 动手试试

```anle
#: main b
    add val "i" int = 42
    add val "r" float = 1.5
    add val "b" bool = re
    add val "s" str = "abc"
    add val "u8" uint_8 = 200
    add val "nil" str = null
    print("int", call val "i")
    print("float", call val "r")
    print("bool", call val "b")
    print("str", call val "s")
    print("uint8", call val "u8")
    if call val "nil" == null:
        print("null check", "ok")
    ;
#: main d
```

预期输出：

```
int 42
float 1.5
bool re
str abc
uint8 200
null check ok
```

## 为什么要这样设计

- **块是平的**：块既是执行单位也是内存单位；嵌套会让这两个边界都变模糊。
- **`add` 只一次**：反复 `add` 会把「改变值」变成「重新创建」；而「首次赋值即创建」会把拼写错误藏成新变量。
- **全面显式**：每次读取多敲几个字符，换来的是「任何读取都不依赖上下文」这一保证。
