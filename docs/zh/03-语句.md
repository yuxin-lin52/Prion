# 03 语句

本章写循环、条件、`match`、赋值与回收。所有结构都用独占一行的 `;` 收束；缩进只是装饰。

## 用 `;` 收体

`if`、`else`、`for`、`while` 以及 `match` 的每个分支都用独占一行的 `;` 收束。`;` 才是结构边界，跟缩进无关——少一个 `;` 会当场解析报错，而不是悄悄改变含义。

## 条件与循环

- 条件必须是真假值，`if 5:` 会被拒绝。
- `for i in 1~5:` 走闭区间整数范围；`for x in 容器:` 遍历列表、键值表和字符串。
- `while cond:` 自由循环；`while cond max 100:` 给循环次数设硬上限（防卡死，而不是禁止死循环）。

## 动手试试：控制流

```anle
#: main b
    add val "sum" int = 0
    for "i" in 1~3:
        val "sum" = val "sum" (+call val "i")
    ;
    print("for range", call val "sum")
    add val "names" list(str) = ["a", "b"]
    for "n" in call val "names":
        print("each", call val "n")
    ;
    add val "count" int = 0
    while call val "count" < 3 max 10:
        val "count" = val "count" (+1)
    ;
    print("while", call val "count")
    add val "v" int = 5
    if call val "v" > 3:
        print("big")
    ;
    else:
        print("small")
    ;
#: main d
```

预期输出：

```
for range 6
each a
each b
while 3
big
```

## match

`match` 解构和类型的值。`case 变体("绑定"):` 绑定载荷，`case _:` 是兜底，守卫用 `if`：

```anle
#: main b
    add type "res" = "ok"(int) | "err"(str)
    add val "r" "res" = "ok"(10)
    match call val "r":
        case "ok"("v"):
            print("ok", call val "v")
        ;
        case "err"("why"):
            print("err", call val "why")
        ;
    ;
#: main d
```

预期输出：

```
ok 10
```

match 的对象必须是编译期已知类型的表达式。穷尽性会检查：给类型新增一个变体，会让每个不再覆盖它的 `match` 暴露出来。

## 重新绑定、增量、下标写与字段写

```anle
val "x" = 5             // 重新绑定
val "x" = val "x" (+1)  // 增量：取当前值加 1 再存回
val "list"[1] = 7       // 下标写
```

增量式 `(+1)` 以当前值为左操作数。写位置（`list[1] = …`、`head.next = …`）要显式写出，如 `val "list"[1] = 7`。
