# 03 语句

## 概述

控制流用 `:` 开体、用独占一行的 `;` 收体。缩进不影响语义。本章定义条件、循环、`match` 与赋值形式。

## 收体

`if`、`else`、`for`、`while` 以及每个 `match` 分支都以独占一行的 `;` 收束。`;` 是结构边界，与缩进无关；缺少 `;` 会解析报错。

## 条件与循环

- 条件必须是真假值，`if 5:` 会被拒绝。
- `for i in a~b:` 遍历闭区间整数范围。
- `for x in 容器:` 遍历列表、键值表或字符串。
- `while cond:` 不限次数循环；`while cond max N:` 以 N 作为防卡死的次数上限。

循环变量是普通的 `val` 名。名字可加引号，也可不加。

## match

`match` 解构和类型的值。`case 变体("绑定"):` 绑定载荷；`case _:` 是兜底；守卫 `case 变体("v") if cond:` 只在条件成立时进入该分支，否则尝试下一个。被匹配对象的类型必须在编译期已知，且覆盖性会做穷尽检查。

## 赋值形式

```anle
val "x" = 5              // 重绑定
val "x" = val "x" (+1)   // 增量：读取当前值，套用表达式后存回
val "list"[1] = 7        // 下标写
val "point".x = 3        // 字段写
```

增量式以当前值为左操作数，且要求该名字已有值。

## 回收

内存在所属块结束时释放；没有提前释放内存的语句。见 [08](08-内存模型.md)。

## 示例

```anle
#: main b
    add val "sum" int = 0
    for "i" in 1~3:
        val "sum" = val "sum" (+call val "i")
    ;
    print("for range", call val "sum")

    add val "names" list(str) = ["a", "b"]
    for "n" in call val "names":
        print("each", call val "n")
    ;

    add val "count" int = 0
    while call val "count" < 3 max 10:
        val "count" = val "count" (+1)
    ;
    print("while", call val "count")

    add val "v" int = 5
    if call val "v" > 3:
        print("big")
    ;
    else:
        print("small")
    ;

    add type "res" = "ok"(int) | "err"(str)
    add val "r" "res" = "ok"(10)
    match call val "r":
        case "ok"("x") if call val "x" > 0:
            print("ok", call val "x")
        ;
        case _:
            print("other")
        ;
    ;
#: main d
```

输出：

```
for range 6
each a
each b
while 3
big
ok 10
```
