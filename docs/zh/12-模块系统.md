# 12 模块系统

单个 `.an` 文件就是一个完整程序。大型程序拆成一个目录里的多个模块。

## 一个文件，一个程序

文件里只要有一个或多个块，它就是程序。不被任何块引用的块都是链根，按源码顺序运行。

## 同文件跨块访问

块之间通过三条显式通道互相访问：传参、返回值、用 `call #:块` 取值。要运行另一个块，写 `call #:块`。

```anle
#: tools b
    add fn "double" (x int) int = x * 2
    add val "constant" int = 9
#: tools d

#: main b
    print("cross fn", call #:tools fn "double"(21))
    call #:tools
    print("cross val", call #:tools val "constant")
#: main d
```

预期输出：

```
cross fn 42
cross val 9
```

## 目录工程

需要多个文件时，用工程目录：

```
myproject/
    main.an        // 入口
    lib.prion      // 可选元数据（如 name = ...）
    util.an        // 其它模块
```

`main.an` 永远是入口。在当前目录即工程时，直接 `prionc build`（不必给名字）即可。

## 跨模块访问

模块用点分路径引用：

```anle
call ##:std.strings #:strings fn "split"(call val "text", " ")
```

- `##:` 指定模块（其文件路径，用 `.` 分隔）。
- `#:` 指定该模块里的块。
- 标准库在 `std.` 下；用 `PRION_STD` 指定根，或按 `<SDK>/lib/prion` 放置。

## 可见性

- 只有当块声明为 `pub` 时，才能跨模块调用。
- `hide` 把某个项从 `pub` 块的公开面里拿掉，使其保持内部：

```anle
#: api b pub
    add fn "public_fn" (x int) int = x
    add hide fn "helper"
#: api d
```

`hide` 作用于 `fn`、`type`、`fix`。`val` 本就在公开面里，不能单独隐藏。
