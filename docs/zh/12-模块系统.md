# 12 模块系统

## 概述

单个 `.an` 文件即一个完整程序；更大的程序组织为包含多个模块的工程目录。跨块、跨模块的访问始终显式。

## 一个文件，一个程序

含一个或多个块的文件即程序。不被任何块引用的块是链根，按源码顺序运行。

## 同文件跨块访问

块之间通过三条通道互相访问：传参、返回值，以及用 `call #:块` 取值。要运行另一个块，写 `call #:块`。

```prion
#: tools b
    add fn "double" (x int) int = x * 2
    add val "constant" int = 9
#: tools d

#: main b
    print("cross fn", call #:tools fn "double"(21))
    call #:tools
    print("cross val", call #:tools val "constant")
#: main d
```

输出：

```
cross fn 42
cross val 9
```

## 工程目录

多文件工程是一个目录：

```
myproject/
    main.an        // 入口
    lib.prion      // 可选元数据（如 name = ...）
    util.an        // 其它模块
```

`main.an` 永远是入口。当前目录即工程时，`prionc build` 不需要名字。

## 跨模块访问

模块用点分路径引用：

```prion
call ##:std.strings #:strings fn "split"(call val "text", " ")
```

`##:` 指定模块（其文件路径，用 `.` 分隔）；`#:` 指定该模块内的块。标准库位于 `std.` 下；用 `PRION_STD` 指定根，或按 `<SDK>/lib/prion` 放置。

## 可见性

- 只有声明为 `pub` 的块才能跨模块调用。
- `hide` 把某项从 `pub` 块的公开面移除：

```prion
#: api b pub
    add fn "public_fn" (x int) int = x
    add hide fn "helper"
#: api d
```

`hide` 作用于 `fn`、`type` 与 `fix`。`val` 本就在公开面内，不能单独隐藏。字段级 `hide` 用于限制单个字段的跨模块访问。
