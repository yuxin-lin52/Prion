# 09 错误处理

## 概述

Prion 没有异常。可能失败的操作返回**和类型**，调用方用 `match` 解构，或用 `?` 向上一层传播。

## 用和类型表示错误

```prion
add type "Result" = Err(str) | Ok(int)
```

错误变体声明在第一位。`?` 把第一个变体视为错误、第二个变体视为成功。

函数成功返回 `Ok(值)`，失败返回 `Err(消息)`：

```prion
add fn "parse" (s str) "Result" = if s == "bad" { Err("oops") } else { Ok(42) }
```

## 用 `?` 传播

在返回同一和类型的函数内，`?` 取出成功值；若结果是失败，则立即返回该错误：

```prion
add fn "doit" (s str) "Result":
    add val "n" int = call fn "parse"(call val s)?
    give Ok(call val "n")
;
```

## 用 match 分发

表达式形态的 `match` 在转换结果的同时透传错误：

```prion
add fn "double" (n int) "Result" = match call fn "parse"("good") { case Ok("v"): Ok(call val "v" * 2), case Err("e"): Err(call val "e") }
```

语句形态的 `match` 在调用处消费结果：

```prion
match call fn "doit"("good"):
    case Ok("v"):
        print(call val "v")
    ;
    case Err("e"):
        print(call val "e")
    ;
;
```

## 示例

```prion
#: main b
    add type "Result" = Err(str) | Ok(int)
    add fn "parse" (s str) "Result" = if s == "bad" { Err("oops") } else { Ok(42) }
    add fn "doit" (s str) "Result":
        add val "n" int = call fn "parse"(call val s)?
        give Ok(call val "n")
    ;

    match call fn "doit"("good"):
        case Ok("v"):
            print("success", call val "v")
        ;
        case Err("e"):
            print("failure", call val "e")
        ;
    ;
    match call fn "doit"("bad"):
        case Ok("v"):
            print("success", call val "v")
        ;
        case Err("e"):
            print("failure", call val "e")
        ;
    ;
#: main d
```

输出：

```
success 42
failure oops
```

## 说明

- 失败是类型的一部分，因此编译器会检查它是否被处理；`match` 的覆盖性会做穷尽检查。
- 没有隐藏的控制流：没有异常展开，也没有清理栈。调用方在返回类型中看到错误。
- 标准库的 `result(T, E)` 与 `option(T)` 基于同一模式构建。
