# 08 内存模型

## 概述

Prion 的回收是确定性的。值由创建它的块拥有，并在该块结束时释放；没有追踪式垃圾回收，也没有引用计数。

## 寿命与释放

块既是执行单位，也是内存单位。块结束时，其值按确定顺序、在确定时点释放。由于块是扁平的，每个值的寿命在源码中可见。

运行时块形成链。不被任何块引用的块是链根，链根按源码顺序自上而下执行；被引用的块在调用处执行，其内存在调用方使用期间保持有效。

没有提前释放内存的语句。要缩短值的寿命，就把它的工作放进一个更早结束的小块。

## 用 take 复制

`call val` 引用最新的值。要获得独立副本，使用 `take`，它按此刻的值做深拷贝：

```prion
add val "a" list(int) = [1, 2, 3]
add val "b" list(int) = take val "a"
```

`take` 作用于 `val`；函数值不占数据，不参与复制。

## unsafe 块

部分能力只在标记为 `unsafe` 的块内可用：

```prion
#: raw b unsafe
    ...
#: raw d
```

在这样的块内可以使用裸地址操作（`read_8` / `write_8` …）、C 互操作（`str_to_c` / `str_from_c`）以及 `asm`。在普通块里这些词**被模式挡住**，这与「名字不存在」是不同的错误。

## 跨块访问

其它块中的值需显式读取：

```prion
call #:tools val "constant"
```
