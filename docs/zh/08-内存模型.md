# 08 内存模型

Prion 是确定性回收：值的存活期正好是拥有它的那个块，没有追踪式垃圾回收。本章讲清所有权规则和你手上的显式工具。

## 块作用域生命周期

块里创建的每个值都归该块所有。块结束时按确定顺序、在确定时点释放。因为块是平的、且块既是执行单位又是内存单位，一个值的生命周期在源码里总是可见的。

不被任何块引用的块是链根，链根按源码顺序从上到下运行。被引用的块在调用处运行，调用方使用它时它的内存是活的。

## 用 take 复制

`call val` 读取引用的是最新的值。当你需要一份独立副本（例如在源值可能变化之后仍要持有数据）时，用 `take` 做深拷贝：

```anle
add val "a" list(int) = [1, 2, 3]
add val "b" list(int) = take val "a"   // b 是独立副本
```

`take` 复制 `val`；它不作用于 `fn`（函数值不占数据）。

## 内存何时释放

块的值在块结束时释放；回收点在编译期由块引用图定死。没有提前释放内存的语句——要缩短值的寿命，就把它的工作放进一个更早结束的小块里。

## unsafe 块

有些能力只在标记为 `unsafe` 的块里可用：

```anle
#: raw b unsafe
    ...
#: raw d
```

在这样的块里可以用裸地址读写（`read_8`/`write_8` …）、C 互操作（`str_to_c`/`str_from_c`）以及 `asm`。在普通块里这些词是**被模式挡住的**，这与「名字不存在」是不同的错误。

## 跨块访问

需要别的块里的值时，显式读取：

```anle
call #:tools val "constant"
```
