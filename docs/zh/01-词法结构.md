# 01 词法结构

本章先带你写并运行第一个 Prion 程序，然后讲清后面整个语言所依赖的那一小套词法规则。

## 第一个程序

新建 `hello.an`：

```anle
#: main b
    print("hello, prion")
#: main d
```

编译并运行：

```
prionc run hello
```

预期输出：

```
hello, prion
```

你写的一切都在**块**里。`#: main b` 打开名为 `main` 的块（`b` 表示 born，开块），`#: main d` 关块（`d` 表示 death，关块）。这里的缩进只给人看，编译器不读缩进。块的规则见 [02](02-基本概念.md)。

## 关键字

以下是保留字：

```
add call fn val type fix give take outs if else for while in max
match case unsafe pub sle ABI hide kill asm and or not
null re fa int float bool str
int_8 int_16 int_32 int_64 uint_8 uint_16 uint_32 uint_64
list map que stack
```

关键字不能直接作名字，但**加引号**就可以：`add val "if" int = 1` 合法，因为名字被引号包住了。

## 符号与标记

普通符号：

```
= : ; ~ , . ( ) [ ] { } + - * / % < > ? & | ^ ! == != <= >= << >>
```

结构标记：

- `#:` 开块 / 关块。
- `##:` 进入模块。
- `###:` 进入包。

## 注释

只有整行 `//` 注释，没有 `/* */`，也不能把注释放到代码同一行的末尾。`//` 之后整行被忽略：

```anle
#: main b
    // 这一行是注释
    print("done") // 这不是注释——它会被当成代码而报错
#: main d
```

把注释单独放一行：

```anle
#: main b
    // 打印 done
    print("done")
#: main d
```

## 字面量

- **整数**默认十进制；也接受 `0x` 十六进制、`0b` 二进制、`0o` 八进制，`_` 可分隔数字：`0b1111_0000` 等于 240。
- **浮点**带小数点或科学计数法：`1.5`、`1e6`、`1.5e-3`。
- **字符串**用 `"…"`，转义只有 `\n \t \\ \"` 四种，其它转义一律编译报错。原样串写 `@"…"`，其中反斜杠是字面量，`""` 表示一个引号。字符串不能跨行。
- **真假值**是 `re`（真）与 `fa`（假）。
- **空值**是 `null`。

## 文件

源文件必须是 **UTF-8 无 BOM** 且 **LF** 换行。一个 `.an` 文件就是一个完整程序或一个模块。带 BOM 或 CRLF 会被编译器明确报错。
