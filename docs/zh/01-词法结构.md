# 01 词法结构

## 概述

Prion 源码为 UTF-8 无 BOM、LF 换行。一个 `.an` 文件即一个完整程序或一个模块。本章定义词法单元：关键字、符号、注释与字面量。

## 最小程序

```prion
#: main b
    print("hello, prion")
#: main d
```

构建并运行：

```
prionc run hello
```

输出：

```
hello, prion
```

所有代码都位于块内。`#: main b` 打开块 `main`（`b` 表示 born）；`#: main d` 关闭该块（`d` 表示 death）。缩进只是排版，编译器不读取缩进。块的规则见 [02](02-基本概念.md)。

## 关键字

以下为保留字，不能用作名字：

```
add call take fn val type hide give outs
if else for while match case
unsafe pub sle ABI asm fix
spawn share send
int float bool str
int_8 int_16 int_32 int_64 uint_8 uint_16 uint_32 uint_64
list map que stack
and or not null re fa
```

名字可加引号，也可不加。只有名字是保留字、或含有不能出现在标识符中的字符时，才必须加引号：关键字只有在加引号时才可作名字，如 `add val "if" int = 1`。循环词 `in` 与 `max` 是上下文词，只在 `for` 与 `while` 语法内有含义，不属于保留字。

## 符号与标记

普通符号：

```
= : ; ~ , . ( ) [ ] { } + - * / % < > ? & | ^ ! == != <= >= << >>
```

结构标记：

- `#:` 打开或关闭块。
- `##:` 进入模块。
- `###:` 进入包。

## 注释

只有整行 `//` 注释；没有块注释，也没有写在代码行末尾的注释。`//` 之后整行由编译器忽略。

```prion
#: main b
    // 这一行是注释
    print("done")
#: main d
```

附加在语句之后的 `//` 会被当作代码解析并报错。

## 字面量

| 种类 | 形式 |
|---|---|
| 整数 | 十进制；`0x` 十六进制、`0b` 二进制、`0o` 八进制；`_` 分隔数字 |
| 浮点 | 小数点或指数：`1.5`、`1e6`、`1.5e-3` |
| 字符串 | `"…"`，转义仅 `\n \t \\ \"`；原样串 `@"…"` |
| 真假值 | `re`（真）、`fa`（假） |
| 空值 | `null` |

除 `\n \t \\ \"` 以外的转义均为编译错误。原样串中的反斜杠是字面量，`""` 表示一个引号。字符串不能跨行。

## 文件约定

编译器会以显式诊断拒绝字节序标记与 CRLF 换行。文件必须保存为 UTF-8 无 BOM、LF 换行。
