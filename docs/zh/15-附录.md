# 15 附录

关键字、内置名、运算符与错误码速查表。

## 关键字

```
add call take fn val type hide give outs
if else for while match case
unsafe pub sle ABI asm fix
trait impl spawn share send
and or not null re fa
int float bool str
int_8 int_16 int_32 int_64
uint_8 uint_16 uint_32 uint_64
list map que stack
```

`in` 与 `max` 是用于 `for` / `while` 的上下文词，不是保留关键字。

## 内置函数

```
print push len char_len nth_char empty has index pop insert remove
clear sort slice concat code char put map que stack keys vals
args read_file save_file exit join run
sle_ms rnd now sqrt print_raw
read_8 read_16 read_32 read_64
write_8 write_16 write_32 write_64
str_to_c str_from_c asm
```

其中 `read_*` / `write_*` / `str_to_c` / `str_from_c` / `asm` 仅限 unsafe 使用。

## 运算符

| 类别 | 运算符 |
|---|---|
| 算术 | `+ - * / %` |
| 比较 | `< > <= >= == !=` |
| 逻辑（单词） | `and or not` |
| 位运算 | `& \| ^ ! << >>` |
| 范围 | `~` |

`debug` 模式下，除零、取模零、整数溢出会在运行时报告。

## 错误码范围

| 范围 | 含义 |
|---|---|
| `E0xx` | 词法（坏字符、坏转义、CRLF/BOM、数字格式） |
| `E1xx` / `E2xx` | 语法与语义检查（名字、类型、块、控制流） |
| `E4xx` | 代码生成 / 链接 |
| `E5xx` | 命令行用法 |
| `E6xx` | 环境（文件、目录、工具链） |
| `R0x` | 运行时错误（越界、溢出、除零、I/O） |

诊断的形态：

```
[E201] error at file.an line 2, column 5, in <context>: <problem>; source: <line>
Expected: ...
Fix: ...
Details: ...
```

## 命令一览

```
prionc build [name] [--mode debug|release] [--opt 0-3]
prionc run   [name] [--mode ...] [--opt ...] [-- args...]
prionc check [name]
prionc fmt   [path] [--check]
prionc clean [name]
prionc -V | prionc -h
```

退出码：`0` 成功，`101` Prion 错误，`1` 用法错误。
