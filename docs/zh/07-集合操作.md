# 07 集合操作

## 概述

Prion 提供四种内置容器：`list`、`map`、`que`（队列）、`stack`（栈）。它们都通过内置函数创建与操作。

## 列表

```anle
add val "l" list(int) = [3, 1, 2]
push(call val "l", 4)
sort(call val "l")
print(call val "l")        // [1, 2, 3, 4]
print(len(call val "l"))   // 长度
print(call val "l"[1])     // 元素（下标从 1 起）
print(call val "l"[1~2])   // 闭区间切片
```

其它列表操作：`insert(list, i, v)`、`remove(list, i)`、`has`、`index`、`empty`、`slice`、`concat`、`sort`。

## 键值表

```anle
add val "m" map(str, int) = {}
put(call val "m", "a", 1)
put(call val "m", "b", 2)
val "m"["b"] = 5           // 下标写
print(call val "m"["a"])   // 读
print(keys(call val "m"), vals(call val "m"))
```

键可以是 `str` 或 `int`。读可能不存在的键之前，先用 `has` 判断。

## 队列与栈

```anle
add val "q" que(int) = que([1, 2])
add val "first" int = pop(call val "q")   // 先进先出

add val "s" stack(int) = stack()
push(call val "s", 1)
push(call val "s", 2)
add val "top" int = pop(call val "s")     // 后进先出
```

队列与栈只能进 / 出；切片与排序仅用于列表。

## 示例

```anle
#: main b
    add val "l" list(int) = [3, 1, 2]
    push(call val "l", 4)

    print("list", call val "l", "len", len(call val "l"), "at", call val "l"[1], "slice", call val "l"[1~2])

    val "l"[1] = 7

    add val "m" map(str, int) = {}
    put(call val "m", "a", 1)
    put(call val "m", "b", 2)
    val "m"["b"] = 5
    print("map a", call val "m"["a"], "b", call val "m"["b"], "keys", keys(call val "m"), "vals", vals(call val "m"))

    add val "qf" int = pop(call val "q")

    push(call val "s", 1)
    push(call val "s", 2)
    add val "st" int = pop(call val "s")

```

## 嵌套容器

容器不能直接装容器。要分组集合，请使用 `map(str, list(int))` 或结构体字段。
