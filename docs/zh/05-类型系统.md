# 05 类型系统

Prion 有标量类型、容器类型、积（结构体）类型、和（变体）类型，以及用 `*` 写的把手（引用）类型。类型之间永不悄悄转换。

## 标量

```anle
int  float  bool  str
int_8 int_16 int_32 int_64
uint_8 uint_16 uint_32 uint_64
```

`re` 和 `fa` 是布尔**值**，不是类型——类型是 `bool`。

## 容器

```anle
list(T)  map(K, V)  que(T)  stack(T)
```

`map` 的键只能是 `str` 或 `int`。容器不能直接装容器；要分组请用 `map(str, list(int))` 或结构体字段。

## 积类型与和类型

```anle
add type "point" = (x int, y int)              // 积：带名字的字段
add type "expr" = "num"(int) | "add"(int)      // 和：变体
```

用 `"point"(3, 4)` 构造积，用 `"num"(7)` 构造变体。用 `call val "p".x` 读字段；用 `match` 解构和类型。

## 把手类型

给自定义类型加 `*` 就得到**把手**（引用）：`point*`。内置标量类型不能加 `*`——它们本来就是值。把手可以为 `null`；读字段前用 `== null` 判一下。

若一个类型的值字段绕回自己就是环，会被拒绝。把其中一端改成把手即可破环：用 `node*` 而不是 `node`。

## 动手试试

```anle
#: main b
    add type "point" = (x int, y int)
    add val "p" "point" = "point"(3, 4)
    print("fields", call val "p".x, call val "p".y)

    add type "expr" = "num"(int) | "add"(int)
    add val "t" "expr" = "num"(7)
    match call val "t":
        case "num"("v"):
            print("num", call val "v")
        ;
        case "add"("v"):
            print("add", call val "v")
        ;
    ;

    add val "q" point* = point(9, 9)
    print("handle", call val "q".x)
#: main d
```

预期输出：

```
fields 3 4
num 7
handle 9
```

## 为什么不隐式转换

`int` 不会自己变成 `str`。需要转换就写出来：`int(v)`、`str(v)`、`float(v)`、`bool(v)`。隐式转换正是类型 bug 的藏身之处，所以 Prion 让它可见。

类型名做存在性检查：废止的或拼错的类型名会报错，而不是悄悄变成新类型。
