# 05 类型系统

## 概述

Prion 区分标量类型、容器类型、积类型、和类型、可空类型、精化类型、类型别名与把手类型。类型之间不存在隐式转换。

## 标量

```prion
int  float  bool  str
int_8 int_16 int_32 int_64  uint_8 uint_16 uint_32 uint_64
```

`re` 与 `fa` 是布尔值，类型为 `bool`。

## 容器

```prion
list(T)  map(K, V)  que(T)  stack(T)
```

`map` 的键只能是 `str` 或 `int`。容器不能直接装容器；嵌套集合请放进 `map(str, list(int))` 或结构体字段。

## 积类型与和类型

```prion
add type "point" = (x int, y int)              // 积：带名字的字段
add type "expr" = "num"(int) | "add"(int)      // 和：变体
```

用 `"point"(3, 4)` 构造积，用 `"num"(7)` 构造变体。用 `call val "p".x` 读字段；用 `match` 解构和类型。

只有一个无名字段的积类型即 newtype：`add type "UserId" = (int)`。用 `"UserId"(42)` 构造，用 `.1` 取值。

## 别名与精化类型

```prion
add type "Len" = int        // 别名：Len 与 int 是同一类型
add val "p" int(>0) = 5     // 精化：条件在编译期检查
```

违反精化条件的值（如 `int(>0) = -5`）会在编译期被拒绝。

## 可空类型与把手

可空类型写作 `?T`：

```prion
add val "found" ?int = null
```

给自定义类型加 `*` 得到**把手**（引用）：`point*`。内置标量类型不能加 `*`，因为它们本就是值。值字段绕回自身的类型构成环，会被拒绝；把其中一端改成把手即可破环。

## 示例

```prion
#: main b
    add type "Len" = int
    add val "n" "Len" = 3
    add val "p" int(>0) = 5
    add val "z" ?int = null
    add type "UserId" = (int)
    add val "uid" "UserId" = "UserId"(42)
    print("alias", call val "n", "refined", call val "p", "nullable", call val "z" == null, "newtype", call val "uid".1)

    add type "point" = (x int, y int)
    add val "pt" "point" = "point"(3, 4)
    print("fields", call val "pt".x, call val "pt".y)

    add type "expr" = "num"(int) | "add"(int)
    add val "e" "expr" = "num"(7)
    match call val "e":
        case "num"("v"):
            print("num", call val "v")
        ;
        case "add"("v"):
            print("add", call val "v")
        ;
    ;

    add val "h" point* = point(9, 9)
    print("handle", call val "h".x)
#: main d
```

输出：

```
alias 3 refined 5 nullable re newtype 42
fields 3 4
num 7
handle 9
```

## 说明

- 类型名做存在性检查；拼错或已废止的名字会报错，而不会成为新类型。
- 转换必须显式：`int(v)`、`str(v)`、`float(v)`、`bool(v)`。
