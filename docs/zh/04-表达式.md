# 04 表达式

## 概述

Prion 使用常规中缀表达式；读取（`call val`）与调用（`call fn`）必须写出动词。本章定义运算符集合、下标 / 切片 / 字段访问，以及 `if` 表达式。

## 运算符

| 类别 | 运算符 |
|---|---|
| 算术 | `+ - * / %` |
| 比较 | `< > <= >= == !=` |
| 逻辑（单词） | `and or not` |
| 位运算 | `& \| ^ ! << >>` |
| 范围（用于 `for`） | `~` |
| 错误传播 | `?`（见 [09](09-错误处理.md)） |

一元负号后必须跟数字字面量。不支持链式比较，如 `1 < x < 5` 应写作 `1 < x and x < 5`。三元运算符 `?:` 不属于本语言，改用 `if` 表达式。

## 下标、切片与字段

这些形式是 `call val` 表达式的一部分：

```anle
call val "list"[1]     // 一个元素（下标从 1 起）
call val "list"[1~2]   // 闭区间切片
call val "point".x     // 一个字段
```

## if 表达式

处于取值位置的 `if` 产生一个值，两个分支类型必须一致：

```anle
add fn "max" (p int, q int) int = if p > q { p } else { q }
```

## 示例

```anle
#: main b
    print("arith", 1 + 2 * 3, 7 % 2)
    print("compare", 5 > 3, 2 == 2)
    add val "b" bool = re
    print("logic", call val "b" and not fa, call val "b" or fa)
    print("bits", 6 & 3, 6 | 1, 1 << 4)
    print("radix", 0xff, 0b1010, 0o17)
    print("escape", "a\nb", "quote \"x\"")
    print("raw", @"a\b")
    add fn "larger" (p int, q int) int = if p > q { p } else { q }
    print("if expression", call fn "larger"(3, 2))
#: main d
```

输出：

```
arith 7 1
compare re re
logic re re
bits 2 7 16
radix 255 10 15
escape a
b quote "x"
raw a\b
if expression 3
```
