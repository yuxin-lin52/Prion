# 04 表达式

Prion 的表达式是普通的中缀表达式，但有两件事永远显式：读取值要写 `call val "名"`，调用要写 `call fn "名"(…)`。本章跑一遍运算符与字面量。

## 动手试试

```anle
#: main b
    print("arith", 1 + 2 * 3, 7 % 2)
    print("compare", 5 > 3, 2 == 2)
    add val "b" bool = re
    print("logic", call val "b" and not fa, call val "b" or fa)
    print("bits", 6 & 3, 6 | 1, 1 << 4)
    print("radix", 0xff, 0b1010, 0o17)
    print("escape", "a\nb", "quote \"x\"")
    print("raw", @"a\b")
#: main d
```

预期输出：

```
arith 7 1
compare re re
logic re re
bits 2 7 16
radix 255 10 15
escape a
b quote "x"
raw a\b
```

## 运算符

- 算术：`+ - * / %`
- 比较：`< > <= >= == !=`
- 逻辑：`and or not`（是单词，不是 `&& || !`）
- 位运算：`& | ^ ! << >>`
- 范围（用于 `for`）：`~`

一元负号后面必须跟数字字面量，如 `-1` 或 `-2.5`。

## 字面量

- 整数：十进制、`0x` 十六进制、`0b` 二进制、`0o` 八进制；`_` 分隔数字。
- 浮点：`1.5`、`1e6`、`1.5e-3`。
- 字符串：`"…"`，转义 `\n \t \\ \"`；原样串 `@"…"`。
- 真假值：`re` / `fa`。空值：`null`。

## 下标、切片与字段

这些都作为 `call val` 表达式的一部分出现：

```anle
call val "list"[1]     // 一个元素
call val "list"[1~2]   // 闭区间切片
call val "point".x     // 一个字段
```

不支持链式比较 `1 < x < 5`；请写 `1 < x and x < 5`。
