# 10 编译期求值

`fix` 是编译期算出值的常量。用于那些永不改变、且希望直接折叠进二进制的值。

## 声明常量

```anle
add fix "pi" float = 3.14159
add fix "buf" int = 4096
add fix "sum" int = 2 * 3 + 4 * 5
```

右值必须编译期可求值：字面量、运算符，以及实参全为常量的 `fn` 调用。

## 读取常量

常量有自己的动词 `call fix`：

```anle
print(call fix "pi" * 2.0)
```

对常量使用 `call val "pi"` 会报错——`val` 与 `fix` 是两个家族，不混用。

## 动手试试

```anle
#: main b
    add fix "pi" float = 3.14159
    add fix "buf" int = 4096
    print(call fix "pi" * 2.0)
    print(call fix "buf" + 1)
#: main d
```

预期输出：

```
6.28318
4097
```

## 通过函数折叠

常量可以调用实参全为常量的函数：

```anle
add fn "double" (n int) int = n * 2
add fix "twice_six" int = call fn "double"(6)
```

## 上限

编译期求值有上限，避免失控的常量表达式把构建卡死。两个旋钮控制上限：

- `--const-depth N`——最大嵌套层数（缺省 256）。
- `--const-steps N`——最大求值步数（缺省 1280000）。

`0` 表示不设上限。超限报的是配额错误，不是语法错误。
